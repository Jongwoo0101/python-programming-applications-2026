4. 일반적 제약사항 (General Constraints)

운영체제 및 크로스플랫폼 제약:

macOS (주 타겟 환경): macOS 11.0 (Big Sur) 이상 (Apple Silicon M1/M2/M3 등 ARM 아키텍처 및 Intel Mac 모두 지원). 특히 macOS 고유의 Aqua 테마 환경에서 GUI 컴포넌트(버튼 색상 무시 등)와 폰트가 깨짐 없이 정상적으로 렌더링되어야 한다.

Windows: Windows 10 (64-bit) 이상 또는 Windows 11 환경에서 특정 OS 종속성 없이 완벽하게 구동되어야 한다.

Linux: Ubuntu 20.04 LTS 이상의 최신 데스크톱 환경(X11 또는 Wayland)에서 파이썬 런타임만으로 실행 가능한 크로스플랫폼 호환성을 보장해야 한다.

디스플레이 해상도: 애플리케이션의 쾌적한 렌더링과 최소 창 크기(960x660) 보장을 위해 모니터 해상도는 1280x720 (HD) 이상이어야 한다.

소프트웨어 및 라이브러리 제약:

개발 언어: Python 3.11.x 이상 환경에서 구동되어야 한다.

GUI 프레임워크: 무거운 외부 라이브러리 설치를 최소화하기 위해 Python 표준 내장 라이브러리인 Tkinter 및 ttk(clam 테마)를 사용하여 사용자 인터페이스를 구현한다.

데이터 관리 및 저장소 제약:

데이터베이스: 별도의 DB 서버 구축 없이 로컬 환경에서 가볍게 동작할 수 있도록 파일 기반의 관계형 데이터베이스인 SQLite3를 사용한다.

파일 I/O: 시스템의 유연성을 위해 퀴즈 및 교재 데이터는 수정이 용이한 JSON 포맷으로 관리하며, 플레이 통계 및 로그는 Excel 등에서 호환되는 CSV(utf-8-sig) 포맷으로 저장한다.
