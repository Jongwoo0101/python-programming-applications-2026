### **6. 작업 내용 (테스트 시나리오 및 결과)**

#### **[테스트 시나리오 1] macOS 환경 GUI 렌더링 및 폰트 호환성 테스트**
* **6-1. 작업 구분:** UI/UX 및 크로스플랫폼 호환성 검증
* **6-2. 테스트 데이터:** * macOS M1 기기에서 기본 `tk.Button`, `tk.Radiobutton`을 사용한 빌드 실행
  * 한글 텍스트가 포함된 `Georgia` 폰트 강제 적용 환경
* **6-3. 테스트 결과: PASS (수정 완료)**
  * *이슈:* macOS Aqua 테마 특성상 버튼의 배경색(bg)이 무시되어 회색으로 출력되고, 영문 세리프 폰트(Georgia)가 한글을 지원하지 않아 궁서체/명조체로 강제 렌더링됨.
  * *조치:* `ttk.Style(theme="clam")`을 도입하여 OS 종속성을 탈피하고 네이비+골드 색상 테마를 정상 출력함. 폰트 패밀리에 `Apple SD Gothic Neo`와 `Malgun Gothic`을 최우선 순위로 배치하여 깔끔한 산세리프(고딕) 폰트로 통일 완료.

#### **[테스트 시나리오 2] 포커 게임 스트리트별 토큰 잔액 검증**
* **6-1. 작업 구분:** 게임 비즈니스 로직 검증
* **6-2. 테스트 데이터:**
  * 학습자 보유 토큰: 1,000 토큰
  * 참여 단위(Ante): 500 토큰 (프리플랍 진행)
  * 플랍 이후 추가 액션 시 잔여 토큰(500)을 초과하는 600 토큰 베팅 시도
* **6-3. 테스트 결과: PASS (버그 픽스 완료)**
  * *이슈:* 기존 로직은 핸드 시작 시점의 Ante만 검증하여 이후 스트리트에서 무한 베팅/콜이 가능했음.
  * *조치:* 매 액션(`_bet`, `_call`) 발생 시마다 플레이어의 실제 잔여 토큰(`tokens - player_total`)을 재확인하는 방어 로직(`_has_enough_for`) 추가. 잔액 부족 시 경고 메시지 출력 및 강제 폴드 처리 정상 작동 확인.

#### **[테스트 시나리오 3] CSV 로거(Logger) 파일 파손 시 예외 처리**
* **6-1. 작업 구분:** 데이터 파일(I/O) 무결성 및 예외 처리 검증
* **6-2. 테스트 데이터:**
  * 내용이 지워진 0바이트의 비정상적인 `game_logs.csv` 파일 삽입
  * 메인 화면에서 '통계 및 기록 조회' 화면 진입 시도
* **6-3. 테스트 결과: PASS (예외 처리 완료)**
  * *이슈:* 빈 파일의 헤더를 읽지 못해 `KeyError: 'username'` 발생 및 프로그램 크래시.
  * *조치:* `_ensure_csv()` 함수에 `os.path.getsize(CSV_PATH) == 0` 조건을 추가. 파일이 비어있을 경우 자동으로 초기 헤더 컬럼(`timestamp`, `username` 등)을 재생성하도록 자가 복구 로직 구현 및 정상 열람 확인.

#### **[테스트 시나리오 4] 일일 베팅 한도 변경 시 토큰 차감 버그 검증**
* **6-1. 작업 구분:** 데이터베이스(SQLite) 업데이트 쿼리 검증
* **6-2. 테스트 데이터:**
  * 현재 보유 토큰: 10,000 / 현재 일일 한도: 100,000
  * 메인 메뉴에서 일일 사용 한도를 50,000으로 축소 설정
* **6-3. 테스트 결과: PASS (이상 없음)**
  * *이슈:* 한도를 줄이면 보유 토큰이 함께 줄어든다는 제보 접수.
  * *조치:* DB 쿼리 분석 결과 `UPDATE users SET daily_limit = ?` 로직 단독 실행 확인. UI 및 데이터베이스 상에서 토큰(`tokens` 컬럼) 손실 없이 한도만 정상 변경됨을 교차 검증 완료.

**7. 비고 (테스트 세부 내용 및 개선 사항)**
* **데이터 관리 구조 고도화:** 기존 하드코딩 되어 있던 퀴즈 문제와 상점 교재 데이터를 JSON 포맷(`quizzes.json`, `textbooks.json`)으로 완전 분리함. 이로 인해 추후 관리자가 소스 코드 수정 없이도 교육 콘텐츠를 쉽게 추가/수정/삭제할 수 있는 확장성을 확보함.
* **패키지 안정성:** `sh1_casino/`, `games/`, `gui/` 디렉터리에 `__init__.py` 패키지 초기화 파일을 추가하여 모듈 임포트 시 발생할 수 있는 잠재적 경로 오류를 원천 차단함.
* **UX 개선:** 사다리타기 미니게임에서 macOS 환경 시 보이지 않던 라디오버튼을 제거하고, 직관적인 '카드형 위젯 클릭 방식(선택 시 금색 테두리 하이라이트)'으로 교체하여 사용자 경험(UX)을 크게 향상시킴.
