# SH1 (시흥랜드) — GUI 기반 카지노 시뮬레이션 프로그램

파이썬프로그래밍응용 팀 프로젝트 (Team: 김시현 - 기획 / 김태양 - 발표 / 원종우 - 개발)

Tkinter GUI + SQLite3(회원/칩/한도) + CSV(게임 로그) 기반으로 만든 교육용 카지노
시뮬레이션입니다. **실제 현금 거래나 사행 행위를 포함하지 않으며, 가상 칩만 사용합니다.**

## 실행 방법

```bash
# 1) (Linux만 해당) tkinter가 없다면 설치
sudo apt-get install python3-tk

# 2) 실행
python3 main.py
```

- Python 3.9 이상, 표준 라이브러리만 사용 (외부 패키지 설치 불필요)
- Windows/Mac은 기본 Python 설치에 tkinter가 포함되어 있어 바로 실행 가능합니다.
- 최초 실행 시 `data/` 폴더에 `sh1.db`(SQLite) 와 `game_logs.csv` 가 자동 생성됩니다.

## 주요 기능

### 1. 회원 관리 (SQLite)
- 회원가입 / 로그인 / 로그아웃
- 아이디·비밀번호(솔트+해시 저장)·닉네임·보유 칩·일일 베팅 한도 관리
- 가입 시 기본 지급: 칩 10,000 / 일일 한도 100,000

### 2. 카지노 게임
| 게임 | 설명 |
|---|---|
| 블랙잭 | 규칙 기반 딜러(16 이하 히트/17 이상 스탠드)와 1:1 대결. 히트/스탠드/더블다운, 블랙잭 1.5배 지급 |
| 포커 (헤즈업 홀덤) | 규칙 기반 AI와 1:1. 프리플랍→플랍→턴→리버 4스트리트, 체크/베팅/콜/폴드. 7장 중 최고 5장 조합으로 쇼다운 |
| 사다리타기 (경마 컨셉) | 5개 레인(x2/x3/x5/x10/x100) 중 선택, 배당이 높을수록 확률은 낮아지도록 설계 |

### 3. 데이터 관리
- **SQLite (`data/sh1.db`)**: 회원 정보, 보유 칩, 일일 베팅 한도
- **CSV (`data/game_logs.csv`)**: 게임 종류, 베팅 금액, 결과, 획득/손실 칩, 플레이 시간
- 기록 조회 화면에서 승률·누적 손익·게임별 통계·전체 로그(Treeview) 확인 가능

### 4. 건전한 게임 이용 기능 (Responsible Gaming)
- 사용자가 직접 일일 베팅 한도를 설정
- 오늘 누적 베팅액이 한도를 초과하면 추가 베팅 자동 차단
- 메인 화면에서 오늘 사용한 베팅액 / 남은 한도 상시 확인 가능

## 설계 메모 (발표/보고서 작성 시 참고)

- **비밀번호 보안**: `salt + sha256` 해시로 저장 (평문 저장 없음)
- **포커 AI**: 정식 GTO 솔버가 아닌 규칙 기반(Rule-Based) 휴리스틱으로, 프리플랍은
  카드 조합(페어/수트/커넥터), 포스트플랍은 현재 최고 족보 카테고리를 기준으로
  0~1 강도 점수를 계산해 체크/베팅/콜/폴드를 결정합니다.
- **사다리타기 확률 설계**: 레인별 확률을 배당의 역수에 비례하도록 정규화해
  모든 레인의 기대값(RTP)이 동일(약 87.5%)하도록 설계했습니다.
- **일일 베팅 한도**: 각 게임에서 실제로 확정된 베팅액(더블다운/포커 콜 총액 포함)이
  판정 시점에 당일 누적액에 더해지며, 한도 초과 시 게임 시작 자체가 차단됩니다.
